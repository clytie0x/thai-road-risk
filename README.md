# ใครเสี่ยงตายบนถนนไทย (Who Is at Risk on Thai Roads?)

หน้าเว็บโครงงานวิชา 344-333 การวิเคราะห์ข้อมูลและการนำเสนอข้อมูลเชิงภาพ กลุ่มบองหลา มหาวิทยาลัยสงขลานครินทร์

- หน้าเว็บ https://clytie0x.github.io/thai-road-risk/
- ไฟล์โครงงานทั้งหมด (รายงาน สไลด์ Power BI โค้ด ข้อมูล) https://drive.google.com/drive/folders/1hgz_0l1_CdgdecM3_f85zfrBWEGGGWej
- ข้อมูลต้นฉบับ ระบบเฝ้าระวังการบาดเจ็บ กรมควบคุมโรค https://opendata.ddc.moph.go.th/dataset/dip-is

หน้าเว็บนี้สร้างจาก scripts/build_web.py ในโค้ดของโครงงาน ตัวเลขทุกตัวมาจากผลวิเคราะห์ชุดเดียวกับรายงาน
